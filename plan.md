## RentGo Afrika NG - Property App Plan

**1. Project Overview:**
   Develop a property application for Nigeria named "RentGo Afrika NG". This platform will connect landlords listing properties with tenants searching for rentals.

**2. Key Features:**

   **a. Landlord Functionality:**
      - User Account Creation: Email/Password sign-up.
      - Verification: Phone number and NIN verification flow.
      - Property Listing: Form to add apartments including photos, price, location (city, state), description, bedrooms, bathrooms.
      - Listing Management: Interface for landlords to view and manage their listings.

   **b. Tenant Functionality:**
      - Property Search: Filters for city, budget (min/max price), and number of bedrooms.
      - Display Options:
         - List View: Compact display of search results.
         - Map View: Interactive map showing property locations.
      - Property Details: Dedicated page for each listing with all details and images.

**3. UI/UX Considerations:**
   - Intuitive and responsive design for web and mobile.
   - Seamless user flows for both landlord and tenant interactions.

**4. Execution Order:**
   - **Phase 1: Frontend Development Kick-off**
     - Frontend Engineer will be tasked with implementing the initial UI/UX flows based on this plan.
     - **Mandatory Step:** The Frontend Engineer MUST run the `generate_images_bulk` tool FIRST and process its output before writing any code.
   - **Phase 2: Backend & Database Integration** (To be planned and executed after frontend foundations are laid).
   - **Phase 3: Testing & Deployment**
